Validar as categorias que a Muse atribuiu

Ferramenta local para os revisores conferirem, entidade por entidade, a categoria sugerida pela LLM Muse. O texto dos artigos e as respostas nunca saem deste navegador. Cada revisor exporta o próprio JSON para permitir a comparação agregada entre humanos e Muse.

sem servidor sem upload não versionar exports

1. Carregar artefatos

Selecione juntos os arquivos batch_*.json e labels_batch_*.json do mesmo conjunto, ou um JSONL consolidado com text e entities.

O exemplo é sintético e serve apenas para testar a interface. Carregue os artefatos privados depois de exportar qualquer teste que queira guardar.

2. Revisar

Cada revisor deve usar seu próprio nome no campo Revisor. O progresso é salvo separadamente por revisor e conjunto de dados.

  • O modo cego (padrão) esconde a sugestão Muse até você responder.
  • Use 1–4 para categorizar e 0 para “não é entidade”.
  • Use M para revelar a Muse, quando necessário.
  • Use U para marcar incerteza e o campo de nota para justificar.

3. Exportar

Ao terminar, exporte o JSON. O arquivo tem apenas identificadores, spans, rótulos, incerteza e notas — não contém o texto integral dos artigos.

  • Envie o JSON para quem consolidará a concordância.
  • O CSV é opcional, para inspeção em planilha.
  • Guarde os exports fora do repositório; eles são dados restritos.

Privacidade e limites

Esta página não faz requisições de rede. O navegador lê os arquivos escolhidos localmente e guarda o progresso no localStorage. Se o navegador bloquear o armazenamento, use a exportação para não perder trabalho. A ferramenta valida a categoria da entidade; ajustes de limite do span, fusão ou divisão de entidades devem ser anotados no campo de observação.

  • M revelar/ocultar a sugestão Muse · U marcar incerteza · ? esta ajuda

Categorias do protocolo

  • IDTY — organização ou instituição (empresa, hospital, órgão, grupo).
  • ACT — ação, incidente ou tipo de ataque (ransomware, phishing, exfiltração).
  • VUL — vulnerabilidade, falha, CVE, zero-day ou configuração explorável.
  • LOC — localidade geográfica (país, estado, cidade, região).
  • NONE — o trecho não deveria ser uma entidade ou o span está claramente inválido.

Independência

Para medir concordância entre humanos, prefira o modo cego desde o início. Se você revelar a sugestão Muse antes de responder, registre isso no campo de observação e avise quem for consolidar os resultados.

Privacidade

Nenhum dado é enviado para servidores. O JSON exportado contém apenas identificadores, spans, rótulos, incerteza e notas. Ainda assim, trate os exports como material restrito e não os versione.
